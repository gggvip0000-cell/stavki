# Ставки

Программа на ноутбуке владельца: в реальном времени берёт коэффициенты футбольных матчей
с odds.ru (российские легальные конторы + Pinnacle), считает честную цену по Pinnacle и
показывает в окне «Можно ставить сейчас» ставки, где коэффициент конторы выше честной цены.
Ничего не ставит и никуда не входит.

- Запуск: двойной щелчок по `Stavki.bat`. Окно программы: http://localhost:8765
- Обновление: кнопка «Обновить» в окне программы (или просто перезапуск `Stavki.bat`) —
  `Stavki.bat` скачивает свежий `stavki.py` из ветки `main` этого репозитория.
- Данные для учёта: `stavki.sqlite3` (цены Pinnacle по времени, найденные ставки).
- Настройки: `config.json` (создаётся при первом запуске).

Откуда числа: способ снятия маржи Pinnacle (степенной) и порог 5% / кф до 4 — из проверки
на 45 685 матчах football-data.co.uk, сезоны 2019/20–2024/25 (21.11.2026).
